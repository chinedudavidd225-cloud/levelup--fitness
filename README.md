# Level Up Fitness
A gamified fitness and healthy-eating PWA (HTML, CSS, vanilla JS). No account needed. Progress is saved on the device.
Educational only. It does not replace advice from a doctor or dietitian.

## Put it online (GitHub Pages)
1. Make a free account at github.com and sign in.
2. Tap + then New repository. Name it `levelup-fitness`, choose Public, tap Create.
3. Tap "uploading an existing file". Upload ALL files: index.html, style.css, script.js, manifest.json, service-worker.js, and the icons folder (icon-192.png, icon-512.png). Tap Commit changes.
4. Go to Settings > Pages. Under Branch pick `main` and `/ (root)`, tap Save.
5. Wait 1-2 minutes. Your link is `https://YOUR-USERNAME.github.io/levelup-fitness/`.
6. On Android, open the link in Chrome, tap the menu (three dots) > Install app / Add to Home screen.
